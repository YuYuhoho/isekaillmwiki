# Raw Sources（不可變原始來源層）

此資料夾存放所有原始參考資料，屬於知識庫的 **Source of Truth（唯一事實來源）**。

## 使用規則

1. **`sources/`**：放置所有文字來源（`.md`、`.txt` 等）。
   - **手動餵料**：直接把你蒐集的文章、筆記、訪談逐字稿丟進這裡，再請 Agent 執行 **Ingest**。
   - **主題委託查證**：也可以直接給 Agent 一個動漫題目（例：「幫我查『作畫』並入庫」），Agent 上網查證後會先在這裡存成 `YYYY-MM-DD-<topic>-research.md`，再跟你討論建卡。
   - 檔案一旦放入即視為**不可變（Immutable）**，Agent 只能讀取或新增新查證檔，不可修改既有來源。
2. **`assets/`**：選用資料夾。
   - 平常做 `.html` 簡報時，Agent 預設會用**原創 Inline SVG 圖解**（離線可用且無版權問題）。
   - 若你有特別想放進簡報的本機圖片或截圖，可放進 `raw/assets/` 並在製作簡報時告知 Agent 引用。
