# Presentations（`.html` 互動簡報輸出層）

此資料夾存放由 Agent 依據 Wiki 卡片與原始來源組裝而成的**單檔獨立 16:9 互動簡報（`.html`）**。

## 設計特色

- **深色劇院沈浸風（Cinema Dark）**：高對比深底配霓虹重點色，凸顯動漫氛圍與投影清晰度。
- **100% 離線可用**：CSS、JS 與原創 Inline SVG 圖解皆內嵌於單一檔案中，雙擊瀏覽器即可開啟，不依賴任何外部網路資源。
- **普羅大眾友善**：由 30 秒輕量卡片展開，補齊生活情境開場、日常類比與無劇透舉例。

## 預設操作快捷鍵

| 按鍵 / 操作 | 功能 |
| :--- | :--- |
| `→` / `Space` / `PageDown` | 下一頁 |
| `←` / `PageUp` | 上一頁 |
| `Home` / `End` | 跳至首頁／末頁 |
| `S` | 開關**講者備忘錄（Speaker Notes）**（含口播稿與補充細節） |
| `G` 或點擊頁碼 | 開啟**投影片縮圖總覽（Grid Overview）** |
| `F` | 切換全螢幕模式 |
| 觸控左／右滑動 | 行動裝置翻頁 |
